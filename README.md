## 🌍 Deploy Using GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload the website files to the repository root.
3. Commit and push your code to the `main` branch.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Choose `main` and `/(root)`.
7. Click **Save**.
8. Wait for deployment to complete.

Your website will be available at:

[`https://RAMKUMAR.github.io`](https://ramkumarit035.github.io/ramkumar_website/
)

## 🔄 Update the Website

After making changes, run:

```bash
git add .
git commit -m "Update portfolio"
git push
```

GitHub Pages will publish the changes after the push completes.
